# dashboard-tutorials
Learning to create a data dashboard with Python.
## What This Project Does

Analyzes 4 years of US retail sales data (9,994 rows) and visualizes key business metrics.

##  Visualizations

- Sales by Product Category (bar chart)
- Yearly Sales Trend 2014-2017 (line chart)
- Profit by Region (bar chart)
- KPI Summary Dashboard (Total Sales, Profit, Orders)

##  Tools & Libraries

- Python, Pandas, Matplotlib, Seaborn
- Google Colab, Kaggle API

##  What I Learned

- Loading and exploring real-world datasets with pandas
- Creating professional visualizations with matplotlib and seaborn
- Using groupby to aggregate business data
- Building a KPI dashboard from scratch

##  Dataset

Superstore Dataset from Kaggle by vivek468
